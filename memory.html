10 / QUESTIONS A SERIOUS BUYER SHOULD ASK

Inspect the boundary before you buy the promise.

What is GridFleet Memory Fabric?

A governed continuity layer for multi-agent operations. Each runtime specialist receives scoped private memory; accepted knowledge can become shared fleet canon.

How is it different from chat history or RAG?

Chat history preserves a thread, and retrieval can find similar material. Memory Fabric adds explicit scope, source freshness, current-fact promotion, superseded history, citations, abstention, and a separate authority boundary.

How does it handle changed or conflicting facts?

Current admissible evidence can supersede an older fact without deleting the historical record. The answer cites the current source and can disclose what changed.

Can every agent read every other agent’s memory?

No. Private cortex stays scoped to the relevant runtime identity. Only governed, accepted knowledge is eligible for shared canon.

What happens when the system cannot find evidence?

It abstains. The contract is to cite admissible evidence or say it does not know.

Does remembered context allow an agent to take action?

No. actionAuthority:false. Memory informs work but grants no permission to act.

Is Memory Fabric available as a standalone API?

Not currently. It is delivered through custom GridFleet deployments. Bring us one real workflow and we will map the architecture around it.
